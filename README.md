# DongYar

Split group expenses and settle debts — offline, no sign-up.

## 🚀 Use It

**→ [tiredasfuck.github.io/dongyar](https://tiredasfuck.github.io/dongyar/)**

## 📲 Install as an App

1. Open the link above in **Chrome** (Android) or **Safari** (iOS)
2. Tap **"Install app"** (Android) or **"Add to Home Screen"** (iOS)
3. Done — works fully offline

## ✨ What It Does

- Add people & expenses (who paid, for whom)
- Smart settlement plan
- PDF report export
- JSON backup & restore
